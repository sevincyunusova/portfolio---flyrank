# Next Case Study Plan

## Where it will go

The next case study will be added to the Projects section of the portfolio.

The project data is currently managed in `app/page.tsx` inside the `projects` array. The new case study will be added as a new project entry there after the work is completed.

## How to add the next case

1. Add the completed project to the `projects` array in `app/page.tsx`.
2. Follow the three-beat case study structure:
   - Problem — what problem or need the project addressed.
   - What I did — my specific frontend work, technologies, decisions, and contributions.
   - Outcome — what was built, what changed, and any measurable result.
3. Add the project's live link and GitHub repository.
4. Add the main technologies used.
5. Check the responsive layout in both dark and light mode.
6. Run the project locally and verify the new project card.
7. Deploy the update and verify the production portfolio.
